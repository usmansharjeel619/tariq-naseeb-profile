# Tariq Naseeb Director Profile

Standalone Astro profile site for Tariq Naseeb, Director of YIWU TARIQ International Trading Co. Ltd.

## Local development

```bash
npm install
npm run dev
```

For inquiries, configure `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, and `CONTACT_FROM_EMAIL` in Vercel Preview and Production environments. Never commit the values.
